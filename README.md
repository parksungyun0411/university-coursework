## 학기별 학습 내용

### 1학년 (2020)
- **1-1 C 프로그래밍**: C 기본 문법, 포인터, 배열, 함수, 중간/기말 시험 코드
- **1-2 Python**: 알고리즘 사고와 기본 문법 (6주차 과제 등)
- **1-2 Java**: 객체지향 기본, 상속/다형성 (기말 과제 포함)

### 2학년 (2023)
- **2-1 자료구조**: Linked List, Stack, Queue를 C로 직접 구현
- **2-1 시스템 프로그래밍**: 리눅스 환경, pipe / fork / file I/O
- **2-2 알고리즘**: Prim, Dijkstra, Cut Vertex 알고리즘을 Java/C++로 구현
- **2-2 데이터베이스**: B+Tree, Slotted Page Structure를 C++로 구현 (DBMS 내부 구조)

### 3학년 (2024)
- **3-1 통계전산처리**: Python으로 통계 기법 구현 (Jupyter Notebook + py 과제)
- *(별도 저장소)* **3-1 네트워크 프로그래밍**: Java Socket 라이어 게임

### 4학년 (2025)
- **4-1 회귀분석 텀 프로젝트**: 축구 선수 데이터를 활용한 회귀 모델링 (R)
- **4-2 비모수통계학**: 부호검정, 순위검정, 커널 밀도 추정, KDE, 비모수 회귀 (R)
- **4-2 다변량 자료분석**: PCA, 인자분석, 군집분석, 판별분석 (R)
- *(별도 저장소)* **4-2 졸업 프로젝트**: 제주어 다중감정분류
